# コード

```JavaScript
const { SlashCommandBuilder, EmbedBuilder } = require('discord.js');

module.exports = {
	data: new SlashCommandBuilder()
		.setName('avatar')
		.setDescription('サーバーのメンバーを選ぶとアイコンを奪い取れます')
        .addUserOption(option => 
			    option.setName('user')
            .setRequired(true)
            .setDescription('メンバー選択')),
	async execute(interaction) {
		const user = interaction.options.getUser('user');

		const embed = new EmbedBuilder()
			.setColor([255,255,0])
			.setTitle(`**${user.displayName}** [**${user.username}**]`)
			.setImage(user.displayAvatarURL({size: 1024}))
			.addFields(
				{ name: `\u200B`, value: `[png](${user.displayAvatarURL({extension: 'png', size: 1024 })})`,  inline: true},
				{ name: `\u200B`, value: `[jpg](${user.displayAvatarURL({ extension: 'jpg', size: 1024 })})`, inline: true },
				{ name: `\u200B`, value: `[jpeg](${user.displayAvatarURL({ extension: 'jpeg', size: 1024 })})`, inline: true }
			)
			.setTimestamp()

		await interaction.reply({embeds : [embed]});
	},
};
```

## コマンドのオプション

.setDescriptionの下に.add..Option(option....を追加するとできます

今回はサーバー内のユーザーを選ぶのをコマンドを使用する際に強制しています

.setRequired(true)が強制でtrueをfalseにすると任意になります。

詳細は[こちら-高度なコマンド作成](https://discordjs.guide/legacy/slash-commands/advanced-creation)と[こちら-解析オプション](https://discordjs.guide/legacy/slash-commands/parsing-options)を参照してください

### おまけ

.addFields内のuser.displayAvatarURL....でクリックするとそれぞれに対応する画像の形式のやつに飛ぶんですが、

extension: 'png', size: 1024 の部分で形式と画質を設定していて一番上のこれだと形式がpngで解像度が1024x1024みたいな感じです。

初期だと結構荒いからこのオプションは入れたほうがよかったりする。
