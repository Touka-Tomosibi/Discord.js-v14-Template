# コード
```JavaScript
const { SlashCommandBuilder } = require('discord.js');

module.exports = {
	data: new SlashCommandBuilder()
  
		.setName('') //コマンド名
    
		.setDescription(''), //コマンド説明
    
	async execute(interaction) {
  
		await interaction.reply(''); //送信される内容
    
	},
};
``` 

<br>
<br> 

## 使用方法  

1. commands/fun/にファイルを作成する
1. 上記のコードをコピー&ペーストする
1. コメントアウトされている部分を埋める
1. 改造したいことがあれば追記や削除をする

※ファイル名はご自由にどうぞ。  
ファイル名の最後に.jsをつけることを忘れないでください

<br> 
<br>

## 例

```JavaScript
const { SlashCommandBuilder } = require('discord.js');

module.exports = {
	data: new SlashCommandBuilder()
		.setName('help') //コマンド名
		.setDescription('helpを表示します'), //コマンド説明
	async execute(interaction) {
  
		await interaction.reply('HELPです'); //送信される内容
    
	},
};
```
